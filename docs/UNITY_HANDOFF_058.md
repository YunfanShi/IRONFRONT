# Unity 0.58.0 — 士兵骨骼与地面移动

2026-10-24。在 `codex/unity-port` 的既有工作上增量修改。用户要求参照现代战术射击游戏改善所有姿态，重点修复趴伏“陆地游泳”。原模型、九款载具、未提交工作与 0.57 构建均保留。

## 动作变化

- 红蓝士兵从17骨升级到18骨，新增腰椎，分开骨盆、腰部、胸廓。沿用旧骨骼热扩散解，只重分配腰胸权重；逐顶点、三角面、UV、材质对比一致。
- 趴伏时骨盆转至水平，胸部略抬、头部前视，肘膝低位支撑；靴子旋转到趴姿。没有把站姿躯干直接折向前方。
- 静止趴伏继续双手持枪；移动时右手持枪，左肘撑地前移/恢复。腿部采用单腿蹬伸、后拖、收膝的交替循环。匍匐侧移与后退分别计算脚部轨迹。
- 走跑与蹲行有独立的支撑/恢复时间，步相由实际位移推进；落脚、抬脚、骨盆与胸部反向转动协调。停止时收回步态，静止有轻微呼吸和错开的落脚位置。
- 枪械保持在真实臂展范围内，极限姿势调整枪的位置；固定骨长，不用伸长手臂补偿。
- 修复实际场景中的接地参照：基地平台顶面比逻辑地形高0.37米，道路有0.09/0.12米铺面高度；所有步兵视觉按可见表面定位，避免膝盖和趴姿埋入平台。地面修正仅影响人物显示，不改变既有碰撞/导航。
- 身体按脚下程序地形的局部坡度倾斜，最高25度。起身/趴下采用更缓和的混合，并抬高过渡期脚部避免穿地。
- AI寻找掩体时站姿移动；掩体内及救援移动使用较慢步速。

## 移动速度校准（有意改变）

旧速度与人形步幅不匹配，特别是2.3米/秒的匍匐。为了让接触时间与位移对应，本次同时调整玩家速度：

| 状态 | 原值 m/s | 新值 m/s |
| --- | ---: | ---: |
| 普通移动 | 8.6 | 4.2 |
| 冲刺 | 13.7 | 6.6 |
| 蹲行 | 4.7 | 2.0 |
| 匍匐 | 2.3 | 0.85 |

修改在 `PrototypePlayer.cs` 的四个速度常量；AI通常移动仍为5.8，救援/掩体内为2.0。速度变化会增加徒步跨图时间，应连同动作一并体验。

## 源文件与运行入口

- `art/characters/refine_soldier_spine.py`：由保留的 `rigged/*-rigged-v01.blend` 生成 `rigged-v02/`；不覆盖v01。
- `art/characters/{blue,red}-soldier/rigged-v02/`：可编辑Blender源文件、三档FBX和骨骼报告。
- `art/characters/validate_refined_soldiers.py`：全新进程回读六份FBX，验证18骨、三份网格、每顶点最多四个归一化权重、1.8米身高与关节变形。
- `art/characters/audit_spine_preservation.py`：新旧源文件的几何、UV、材质一致性校验。
- `SoldierArtAssetSetup.Build`：导入v02，重建实际红蓝资源预制体、共享LOD骨架和第一人称手臂网格。Blender/FBX骨名与Unity左右转换保持原接入约定。
- `PrototypeSoldierVisual.cs`：姿势与接触求解。`PrototypeSoldierArtRig.cs` 按骨盆→腰椎→胸部/四肢顺序同步，避免父骨后更新导致二次变形。
- `PrototypeSoldierMotionProbe.cs`：只有显式 `-ironfrontMotionProbe <绝对输出目录>` 才创建。使用实际运行时姿势代码与蒙皮，在30fps固定采样的平面网格上验证；镜头跟随角色位移。
- `SoldierMotionPlaySmoke.Run`：编辑器播放模式启动上述探针；不加`-quit`，探针完成自行退出。
- `PrototypeInfantryLocomotionSmoke` 已换用真实蒙皮臂长/腿长，保留原预览菜单；不再以隐藏的旧圆柱/方块网格判断新士兵接触。

证据根目录：`art/characters/motion-refinement-2026-10-24/`。该目录的最终验证报告记录实际构建、运行与视频结果。

- `play-results.txt`：160项红蓝三档LOD、持握、第一人称、摩托驾驶/乘客与联网角色生成路径检查。
- `batch-results.txt`：视角、装备、九款载具28次座位切换、大厅配装、步兵动作五组回归；步兵为双方/三武器/六状态/24相位，共864个姿态。
- `motion-editor/`：11组、900帧连续采样，包括走跑、蹲行、正/侧/后匍匐、静止瞄准、侧移/后退和站趴过渡；`samples.csv` 记录肘膝高度、最低点、握持误差和接触期间脚踝位移。
- `development/`：实际战场红蓝士兵、普通第一人称和摩托两座位截图；探针临时给现有平台网格添加测试碰撞体，从实际网格射线取高度，独立验证蒙皮最低点，正常运行不添加该测试碰撞体。
- `fresh-fbx-audit.json`、`preserved-geometry.json`、`original-preservation.json`：导出回读、旧模型保护证据。
- `baseline/`：任务开始时的相关代码、版本文件与v01骨骼源文件副本。旧完整交付在 `soldier-integration-2026-10-24/`。

## 范围边界

这是本项目原创的程序化动作与IK改进，没有导入或复制《战地6》《三角洲行动》的商业动画，也不声称达到动作捕捉系统的覆盖范围。参考来源及未能逐帧检查的官方素材在 `reference_notes.md` 如实记录。

地形适配是局部斜面估计，未实现任意台阶、障碍物上的逐肢攀爬/全身接触求解。合并的手套手指增加了撑地张开控制，仍不是逐指动画。未验证跨机器联网会话；联网角色生成和同一视觉驱动路径已检查。
