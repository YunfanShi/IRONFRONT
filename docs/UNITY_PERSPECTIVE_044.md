# 0.44.0 Unity 步兵第三人称与载具第一人称

## 目标与参照

玩家要求步兵改为第三人称，驾驶或操纵载具时改为第一人称。参考视频 `1626639050-1-192.mp4` 的车载瞄准段展示了从车上向前观察、画面中央瞄准与距离信息的感觉。本轮以用户指定的视角分工为准，保留 Unity 原有的 `AIM`、`BARREL` 双标记及炮塔转向速度；不照搬参考游戏的美术、界面和载具数值。

此前 Unity 步兵相机在眼前，枪械直接挂在相机下；进入 R4、T90 或 U8 后相机在车后 5.4 米。直接交换相机位置会造成看不到玩家身体、步兵弹丸从镜头后方出发、手雷和火箭从空中出现、车辆镜头钻入装甲等问题。

## 实现

| 场景 | 相机与角色 | 射击和状态 |
| --- | --- | --- |
| 步兵站立/跑动 | 相机从右肩后方约 3.4 米跟随，右键瞄准时靠近到 1.65 米并收窄视野。相机从人物肩部到目标位置作球形遮挡查询，靠墙时前移，避免穿墙。玩家沿用 AI 士兵的低多边形全身模型，并显示当前主/副武器、阵营和兵种装备 | 准星仍在画面中央；先用相机射线找瞄准点，再从人物所持枪的枪口朝该点发射实体弹丸。手雷与火箭也从人物附近出发，火箭朝视线目标飞行；障碍物仍能拦截弹丸 |
| 蹲下、趴下、滑铲 | 镜头焦点随姿态降低，人物外观随姿态缩短；装备切换、复活后更新可见枪模 | 既有速度、碰撞体、开镜、换弹和伤害规则沿用 |
| 倒地与扶起 | 地面镜头位于倒地身体后侧，保留水平 170° 观察范围；扶起后回到肩后 | 保留 4 秒医疗兵救援、呼救和放弃流程 |
| T90 | 相机位于炮塔前方炮手瞄具附近，缩窄到 56° 视野 | `AIM` 表示即时目视方向，`BARREL` 表示实际炮管方向；炮塔、炮弹及装填间隔沿用 |
| R4 | 相机位于机枪塔前侧，72° 视野 | 炮塔照常追随视线，机枪仍从真实枪口发射 |
| U8 | 驾驶位从挡风玻璃前方看路，机枪位从武器座前方看前方，72° 视野 | `F1/F2` 换座同步移动镜头；驾驶位不发射机枪，机枪位可瞄准与开火 |

上车隐藏人物与步兵武器；下车、载具毁坏和重新部署恢复步兵模型与肩后镜头。`IPrototypeVehicle.CameraPosition` 为每辆车提供随车移动的第一人称观察点，避免继续复用步兵的眼高或车后追随位置。编辑器菜单 `IRONFRONT → Preview Next Vehicle Sight` 依次预览 T90、R4、U8 驾驶位和 U8 机枪位；`Preview U8 Gunner Sight` 可直接检查 U8 机枪位。

## 验证与范围

- Unity 6000.5.10f1 的 `SampleScene` 在 Play 模式运行，Console 0 错误、0 警告。目视检查步兵肩后人物与枪模、T90 炮手视野、R4 车载机枪视野、U8 驾驶位和机枪位的前方视野，均能看见道路和目标，没有把镜头放进不透明车身。
- `IRONFRONT → Verify Player and Vehicle Cameras` 输出 `IRONFRONT perspective PASS`：验证人物在镜头前、步兵弹丸从枪口出发、三类车辆的第一人称观察点、U8 换座以及各车下车后回到第三人称。
- `IRONFRONT → Verify Downed View and Revive` 输出 `IRONFRONT downed view and revive PASS`：地面观察、170° 水平限制和医疗兵连续 4 秒扶起通过；目视确认倒地时人物在镜头前而非包住镜头。
- 既有 `IRONFRONT → Verify Tank and Respawn` 输出 `IRONFRONT smoke PASS`：坦克起步、转角行驶、主炮装填间隔和毁车弹出未因视角切换回退。
- `tsc --noEmit` 和 `scripts/verify-core.cjs` 通过；这些是网页类型与核心逻辑回归，不能代替 Unity 实机检查。Unity 编辑器成功构建 macOS 独立程序 `UnityProject/Builds/macOS/IRONFRONT.app`，`Info.plist` 中的应用版本为 `0.44.0`。关闭先前仍在运行的旧版实例后重新启动构建，主菜单显示 `0.44.0`，按 Enter 进入攻防，独立程序中可看到身后的玩家全身模型、装备和前方准星。
- 本次改变的是现有三类可驾驶车辆与本地玩家的视角。尚未实现的五类载具仍按还原清单的 S5 处理；联机访客尚不能驾驶载具。人物动画仍是程序化摆臂、摆腿和比例变化，最终角色骨骼动作、美术和长时间不同地图边角的镜头遮挡仍需后续验收。
