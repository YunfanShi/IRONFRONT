# 0.22.0 Unity 步兵兵种、出击界面与构建入口

## 目标与基线

本轮从 `codex/unity-port` 的 `12f7bee`（0.21.0）继续开发。此前 Unity 原型可在编辑器完成单地图征服短局，但玩家和八名 AI 使用同一种枪，进入场景立即开战，没有出击选择界面，也没有可重复的桌面构建入口。本轮把网页游戏四兵种的基础差异移植到当前步兵局，保持 Unity 开发分支与 `main` 分开。

## 实现范围

- 新增 `PrototypeInfantryRoles.cs`：突击、医疗、侦察、工程四兵种；七种网页武器的参数表。当前每名士兵只装备一把默认主武器：突击 IF-27、医疗 VX-9、侦察 M89、工程 BR-44。射速、弹匣、备弹、装填、散布、射程及距离衰减接入玩家射击；AI 按兵种使用武器与弹药，并在有限可见范围内作战。
- 玩家和 AI 共用 `PrototypeInfantryKit` 的换弹、支援次数与冷却。突击 X 补充自身或 12 米内友军备弹；医疗 X 治疗存活且受伤的自身或 8 米内友军；侦察 X 仅将视野内、无遮挡的最近敌人位置上报指挥官；工程 X 为自身或 8 米内友军提供最多 35 点可消耗护甲。每次出击两次支援，成功使用后冷却 10 秒。AI 医疗、补给与护甲会在附近有合适目标时自行使用；侦察 AI 的目视距离增至 110 米，其他兵种为 85 米。
- 新增 `PrototypeFrontend.cs`：编辑器或独立程序进入场景后先显示单人出击界面，选择兵种再开战。菜单支持鼠标、数字键 1–4 与 Enter；战局开始前票数和 AI 不推进。HUD 显示当前武器、护甲与剩余技能次数。2x Game 视图中右侧操作说明按单列排列。
- 新增 `Assets/Editor/PrototypeBuild.cs`：Unity 菜单 `IRONFRONT > Build macOS Standalone` 及批处理入口，在构建前检查启用的场景与十个原型脚本。产物位置为 `UnityProject/Builds/macOS/IRONFRONT.app`。运行方法和冒烟清单见 [UNITY_BUILD_022.md](UNITY_BUILD_022.md)。
- 按 `ForAgent.md` 的新模块规则，开发分支版本升为 0.22.0；网页包、菜单、房主状态和客户端房间版本门槛同步。网页房主服务更新时需重启，0.21.x 与 0.22.x 客户端不互通。

## 验证

- 本机 Unity 6000.5.10f1 随附 Roslyn 对十个运行时脚本及新增 Editor 构建脚本静态编译通过。
- Unity 编辑器实际刷新资源并 Play `SampleScene`：主菜单显示并可选兵种；选择医疗兵后战局 HUD 显示 VX-9 与 36/180 弹药；选择工程兵后按 X，HUD 护甲升至 35、技能次数从 2 降至 1。2x Game 视图中的操作说明重排后可读；Console 显示 0 错误、0 警告。
- 桌面构建与独立应用启动结果见 [UNITY_BUILD_022.md](UNITY_BUILD_022.md) 与根目录 `QA_REPORT.md`；编辑器 Play 不替代独立程序验收。

## 当前限制

本轮仍是单地图、100 票步兵征服短局。每兵种只提供默认主武器，尚无完整配装、手雷、医疗救起、工程载具修理或火箭、侦察信标、载具、多人联机、完整模式选择与正式美术。工程护甲是当前步兵原型的临时战术能力，不等同于网页工程兵载具装备。网页 LAN 的回归测试不证明 Unity 联机可用。
