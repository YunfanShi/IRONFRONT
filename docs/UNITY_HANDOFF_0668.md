# 0.66.8 — 手指加厚

## 请求与修改

用户在 0.66.7 后要求手指更大或更厚。本版以 `8e0784b` 为基线，对 P8、IF-27 红蓝两队第一人称手套的五指增加约 10% 横向体积感。具体采用横截面加粗，不增加指长、不移动关节。

`art/characters/finger-volume-2026-10-27/build_fingers.py` 直接打开保留的 0.66.7 源文件。对各指节计算垂直于骨轴的径向偏移，再投影到整根手指的横截面；以现有指节权重混合，指根平滑过渡。系数为 0.10；混合区域的实际变化依权重而定，不等于每个截面精确统一放大 10%。

没有整体缩放手掌或手臂。无指节权重的掌部、腕口、袖管和护臂表面逐顶点保持一致；指根邻接的有指节权重区域参与过渡。骨骼、拓扑、权重、材质、握点、动作数据与驱动保持一致。第三人称和其他枪械继续原资源。

## 源资产验证

`validate_fingers.py` 对双队三档 LOD 做源文件直接比较，再清空场景逐一重新导入六份 FBX。

- 身体、46 根骨骼的静止矩阵和层级、30 根独立指节、所有网格拓扑与权重一致。
- 每条候选手臂有 1511 个带指节权重的顶点位移；其余顶点坐标完全一致。
- 最大源坐标偏移约 1.545 mm；单指影响顶点沿指长方向的最大误差约 0.000038 mm。
- 未产生面翻转或面积塌缩；相对基线最大面法线变化约 15.49°。
- 六份 FBX 均有 46 骨、30 指节、最大 4 个权重，权重归一化误差小于 2e-5。

中性手部诊断图使用原始手套网格副本、统一灰色材质和固定相机，包含掌面、背面、侧面、斜视；不将该诊断材质写回游戏模型。最终灯光为降低过曝后的版本。几何和动作参考沿用此前已获授权的手部模型与用户提供的士兵动画，本轮没有引入新的外部资产。

## 实机检查与边界

独立 `hand-candidate-v08` 资源导入与 Unity 0.66.8 构建均 PASS。`motion`、`rig` 两组实际应用检查 PASS，RuntimeErrors=0，涵盖双队、瞄准中心、手臂和独立指节、换弹中断复位等既有检查。

已查看两枪第一人称持枪／瞄准／换弹关键帧，及同机位反向接触对照：P8 握把与扳机护圈、P8 拉套筒、IF-27 握把和抓弹匣。中性张手图的指间空隙保持可辨；所查接触画面未见加厚造成明显的新穿插。原始关键帧与连续采集在 `checks/finger-motion`，反向近照和等比例裁切保留原始亮度。

本轮不重做原有握姿或换弹动作；自动 PASS 不代表所有角度和每帧均无穿插。458 张实机帧无空白／品红错误；录像为 306 帧、30 fps、10.2 秒，独立解码 8 个时间点通过，未在 UI 中连续播放观看。最终范围记录在 `delivery.json`；不宣称用户已经完成视觉验收。
