# 0.35.0 Unity 步兵操作与战斗 HUD

## 本次完成

- 重新排版 Esc 暂停菜单。标题分成中文主标题与英文状态行，连接信息、灵敏度和音量各有足够的文字高度；面板改为深色并降低背景遮罩强度，避免旧版文字裁切及整屏发灰。继续战斗、返回大厅和两项滑块保留原有功能。
- 第一人称枪模改为更清楚的机匣、护木、导轨、准星、握把、枪托、枪口和瞄具层次，收窄并前移持枪位置。`R` 换弹时枪身下沉、旋转，弹匣随装填进度下移再复位；弹药仍在既有装填计时结束时补入。
- 按住鼠标右键开镜：枪械瞄具向屏幕中心移动，视野角度缩小，射击采用该武器的 `AdsSpread`。松开右键恢复腰射；开镜时可低速移动，也可趴下开镜。狙击枪使用更窄视野。射击的最后一发仍按按下扳机时的瞄准状态计算散布。
- 中央准星改为带深色外沿的四段线和中心点；移动、冲刺与刚开火时准星扩张，开镜时缩小。顶部中央增加蓝队、红队实时剩余部署数与 A–E 据点控制色块，战局票数直接读取 `PrototypeMatch`；左右调试信息面板收紧并换为深色。
- `LeftShift` 向前冲刺，`C` 切换蹲下；在冲刺且着地时按 `C` 触发短时滑铲，结束后保持蹲姿；`V` 在趴下与蹲姿之间切换。不同姿态对应移动速度、碰撞胶囊高度、视角高度和持枪姿态。蹲姿起身会检查头顶空间，避免直接穿入障碍物；进入载具及复活时恢复站姿。
- 项目版本更新到 `0.35.0`，包括 Unity 包版本、起始菜单及仓库版本。

## 操作与验证方法

1. 用 Unity 6000.5.10f1 打开 `UnityProject/Assets/Scenes/SampleScene.unity`，运行后按 Enter 进入单人战斗。检查顶部蓝红票数随战局变化，A–E 据点颜色随归属变化；中央准星和右下弹药信息同时可见。
2. 按住鼠标右键检查瞄具是否对准屏幕中央、FOV 是否缩小；松开后恢复。射击后准星短暂扩张，弹匣数字减少；按 `R` 时观察枪和弹匣动作，装填结束后弹匣与备弹数字变化。
3. 按 `C` 蹲下，再按 `V` 趴下，再按 `V` 回蹲姿、按 `C` 起身；对比视角高度与左上状态字。向前移动并按住 `LeftShift` 冲刺时按 `C`，应先滑铲再进入蹲姿。在低矮障碍下尝试起身，站立胶囊空间不足时应保持蹲姿。
4. 按 Esc，检查所有标签完整显示，滑块可调整，继续和返回大厅按钮可点击。单人暂停应冻结战局，联机暂停仍遵守现有房间规则。

## 本轮实测

- Unity 编辑器重新导入脚本后 Console 为 0 错误、0 警告；运行起始场景并按 Enter 进入单人战斗，顶部票数、据点控制色块、枪模和四段准星正常显示。
- 进入战斗后按 Esc，连接信息、灵敏度、主音量标签完整显示，没有旧版的文字裁切；按 Esc 可返回战斗。按 `C` 和 `V` 后，左上状态分别显示 `CROUCHED` 与 `PRONE`，镜头高度改变。
- Unity 编辑器菜单 `IRONFRONT → Build macOS Standalone` 构建成功，输出 `UnityProject/Builds/macOS/IRONFRONT.app`；仓库 TypeScript `tsc --noEmit` 通过。
- 开镜持续按键、滑铲组合输入和换弹全过程仍需在实体键鼠下做手感复测；编辑器自动化仅能逐键触发，无法可靠保持鼠标右键及 `Shift+W` 多键持续输入。

## 当前边界

第一人称枪械仍是项目内的程序化低多边形模型，尚无完整骨骼动画。换弹表现驱动当前视角的枪和弹匣，第三人称角色没有同步换弹动作。蹲下、趴下、滑铲与开镜首先用于单人玩法；现有联机快照没有传输姿态和开镜状态，其他玩家暂时看不到对应的第三人称动作。

开发提交保留在 `codex/unity-port`，不合并 `main`。
