# 0.30.0 Unity 坦克驾驶与部署复活

## 范围与参照

本轮以仓库 `main` 的 `src/vehicles/Vehicle.ts`、`src/core/Battle.ts` 和 `src/ui/UI.ts` 为规则参照，把 Unity 的 T90 从展示模型接入现有载具系统，并将自动回基地复活改为濒死救援、阵亡等待和手动选点部署。网页战斗代码未重写。Unity 原型仍沿用自身射线武器和简化兵种系统。

| 规则 | `main` 参照 | Unity 0.30.0 |
| --- | --- | --- |
| T90 装甲、运动 | 820 HP、前进 10 m/s、倒车 4 m/s、加速度 5、转向 0.7 rad/s | 同数值，玩家驾驶时按地形和车体净空移动 |
| T90 主炮 | 145 伤害、2.4 秒射击间隔、230 m 射程 | 同数值；鼠标瞄准、炮塔转向、射线命中和曳光线 |
| 坦克损毁 | 120 秒后在基地重生 | 同等待时间；损毁时驾驶员离车，车损扣 0.5 票 |
| 步兵濒死 | 30 秒救援窗口，可呼叫医疗兵、加快放弃 | 同等待时间；己方医疗兵到达 3.5 m 内可救起；H 呼叫，按住空格加快放弃，也可点按钮立即放弃 |
| 阵亡与复活 | 正式阵亡扣 1 票，4.5 秒后选点 | 同计时；玩家手动部署，成功前不会自动回基地 |

## T90 操作

- 双方基地各有一辆坦克，位置沿用网页基地附近的坦克出生点。玩家只能驾驶己方空车；靠近按 `E` 上车，`WASD` 驾驶，鼠标调整瞄准方向，左键开炮，再按 `E` 下车。
- T90 使用现有车辆 HUD、车载镜头、命中判定和票数系统。被击毁时驾驶员正式阵亡，坦克隐藏渲染和碰撞，120 秒后仅在出生点无阻挡时恢复。敌方步兵和载具能伤害 T90。
- 房主快照同步 T90 的位置、朝向、装甲和存活状态给访客；访客当前只能观看坦克，不能申请驾驶座。炮塔朝向、开炮瞬时效果及驾驶座占用尚未单独同步。

## 复活流程

步兵受到致命伤害后进入濒死状态。医疗兵会优先靠近己方濒死玩家并施救；救援呼叫扩大医疗兵的搜索范围。若 30 秒内未获救、主动放弃，或驾驶载具时受到致命伤害，进入正式阵亡并扣票。4.5 秒准备结束后，部署界面可选择：

1. 己方主基地；
2. 己方已控制据点；交战中的据点改在外围寻找安全位置；
3. 安全、存活且未乘车的首个小队成员；
4. 单机或房主玩家可选空闲己方载具驾驶位，包括 T90。

部署时重新寻找无建筑、载具、士兵和可见敌军威胁的位置。地图候选可能随战局变化而失效，点击时再次复核。Unity 尚无网页的信标系统，因此没有信标出生点；Unity LAN 访客继续限定为突击兵步兵，不能通过部署界面进入载具。

## 联机权限

访客仅发送 `deploy` 的地点标识以及 `downed` 的救援或放弃动作。Node 房间服务以实际连接绑定玩家 ID，检查地点格式、房间阶段并限速；它不接受访客自报阵营、身份、坐标或 `peerDeploy`/`peerDowned` 事件。Unity 房主再根据自己模拟的玩家状态检查濒死/等待计时、阵营、据点归属、队友安全与碰撞，只有通过后才改变位置和生命值。房主仍独占战斗快照和房间管理权限。

新增消息改变了旧服务的复活能力，Unity 房间协议从 `unity-1` 升到 `unity-2`，客户端在创建或加入时拒绝旧协议。网页包、房主状态、网页客户端版本门槛和 Unity 应用版本同步升到 0.30.0；升级后需要停止旧 `npm run lan` 进程并重新启动。
