# 0.27.0 Unity 步兵与车辆模型细节

## 目标与基线

本轮从 `codex/unity-port` 的 0.26.0 继续。开始时本地 `HEAD` 与 GitHub `origin/codex/unity-port` 均为 `84b330d`。此前网页 `main` 的士兵由头盔、面罩、护甲、弹袋、手脚和武器等低多边形分件组成；Unity AI 步兵仍是一整个彩色胶囊体，第一人称枪械是一根方块。Unity 的 R4 与 U8 已可战斗，但外观只有基础车身、轮子和机枪。此次按网页模型的造型和低饱和军事配色做一次适度提升，继续留在开发分支，不合并 `main`。

## 实现

- 新增 `PrototypeSoldierVisual.cs`。AI 和联机访客共用分件士兵：制服、胸甲、背包、腰带、弹袋、肩甲、面部、头盔、护目镜、护颌、耳护、手臂、腿、护膝、靴子和手持武器。蓝队以灰蓝色区分，红队以灰棕色区分；护甲、皮肤、镜片、枪械使用共享 URP 材质。四兵种手持武器长度与瞄具不同，医疗兵肩部有识别标记。
- 士兵腿与手臂根据实际水平位移摆动，进入找掩体或掩体状态时降低身体姿态。出生、死亡、乘车、下车及网络快照继续控制分件模型可见性。AI 原来的胶囊渲染器只被隐藏，碰撞体与命中、视线、导航、占点规则保持原样；分件没有独立碰撞体。
- 玩家第一人称四兵种枪械改为机匣、护木、枪管、枪口、弹匣、握把、枪托、瞄具和手套/衣袖的组合，并在选兵种时切换外形。武器外形不改变伤害、散布、射速或弹药规则。
- R4 侦察车增加车窗、车顶、侧面装甲、车门、门把、车灯、格栅、轮毂与机枪护盾；U8 运输车增加引擎盖、前格栅、车顶装饰、车门、侧踏、车灯、尾门、轮毂与枪盾。车身颜色改为接近网页车辆的灰蓝/灰棕。车轮、炮塔和原有车体碰撞仍按原系统工作。
- 新脚本纳入独立构建必需文件检查。按 `ForAgent.md` 的新功能规则升为 0.27.0，并同步网页包、房主状态、客户端版本门槛及 Unity 应用版本。构建产物仍位于 Git 忽略的 `UnityProject/Builds/macOS/`。

## 验证

- Unity 6000.5.10f1 刷新并编译后进入 `SampleScene` 的 Play 模式，出击菜单及实际单人战局正常显示；第一人称枪械、附近 R4/U8 和远处步兵出现，Console 0 错误、0 警告。此次是短时画面检查，不是长时间战局或所有视角的美术验收。
- `IRONFRONT/Build macOS Standalone` 构建成功，输出 `IRONFRONT.app`，Unity 报告大小 116,643,813 字节；`Info.plist` 的应用版本为 0.27.0。
- TypeScript `tsc --noEmit` 通过；`scripts/test-unity-room.cjs` 房主权限回归通过；`scripts/test-lan.cjs` 网页双客户端 LAN 回归通过。两项 LAN 测试是版本同步回归，不代表本轮已完成跨机 Unity 实战。

## 当前限制

这是 Unity 原型的低多边形细化，仍用 Unity 基础几何体实时组合，没有移入网页的 InstancedMesh、布料纹理或完整角色动画；近看仍能看出分件接缝。场景建筑和地形仍是占位美术，第一人称武器暂无完整开火、换弹和后坐力动画。联机职业、载具座位及双机长期测试范围保持 0.26.0 的状态。后续若继续提升画面，应先加入可复用网格、纹理与动作，再针对战场视距进行性能检查。
