# Unity 0.60.0 — 人物受击方向与屏幕边缘反馈

2026-10-24。新增人物实际扣血时的方向提示与短暂红色边缘闪烁。保留已有模型、枪托、0.59.3跑步镜头/上身动作、移动规则、命中敌人反馈及旧程序。

## 体验规则

- 受到有效伤害后，屏幕四周出现向内渐隐的红光，0.48秒内消退。伤害量较大或连续命中会增强，透明度上限0.68；画面中心保留透明区域。
- 准星外围红色弧与小箭头指向伤害来向：前方在上、后方在下，左右对应屏幕两侧。转动镜头时，标记按受击时记录的世界方向重新投影，不跟踪敌人后续移动。
- 单个方向保留1.1秒，后0.65秒淡出；近似同向连击合并，最多四个方向，满额替换最早项。
- 来源不明只闪红光。零伤害、负数/非有限值、被友军规则排除的子弹不会触发。
- 暂停、补给菜单、其他前台菜单、倒地和复活清空残留。两种步兵视角均使用相同反馈；只对人物实际扣血触发，不将车辆装甲扣血混作人物受击。

## 实现和来源

`PrototypeDamageFeedback` 使用项目已有UI Toolkit模块，与现有HUD并存；复制已有PanelSettings用于独立透明覆盖层，USS只规定全屏布局，程序生成渐变网格和方向弧。根元素与自绘元素均为PickingMode.Ignore，不拦截输入。没有增加第三方包、图片素材、受击相机抖动或全屏遮挡。

`PrototypePlayer.TakeDamageFrom` 在护甲吸收后根据实际生命损失通知反馈；原`TakeDamage(float)`入口继续可用。普通弹记录发射位置，即使发射者已消失仍可得到方向；炮弹/火箭使用爆炸中心；新增载具弹根据是否具有爆炸范围选择发射点或爆心。远端人物记录同样的伤害信息，手雷也把爆心传给远端目标。原有伤害数值、友伤、护甲和计分计算保持。

`PrototypeLanActor.incomingDamage` 为可选字段，含递增序号、来源、实际伤害与事件年龄；主机发送，接收端仅在生命减少时显示。第一次快照只记录基线，重复/旧序号不重放，复活清空；旧主机缺少该字段时仍根据生命减少给出无方向红光。同一快照间隔内多次受击合并生命损失，并使用最近一次命中的来源。实际房间服务原样中转玩家数据，不需要修改服务端协议版本。
