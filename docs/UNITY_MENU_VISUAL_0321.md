# 0.32.1 Unity 初始界面视觉修订

## 问题与目标

0.32.0 已有大厅、作战、配装、设置及单人和 LAN 入口，但实际画面仍是大块黑色面板加一小块人物预览。它没有呈现参考图中的机库空间，主标题、角色和操作入口也缺少明确的视觉主次。本次按用户提供的网页游戏截图重新检查 Unity 编辑器中的真实画面，再调整首次进入游戏时的四页菜单。

## 改动

- 将右侧 512 × 512 人物预览改成覆盖整个菜单的 1280 × 800 独立机库画面。机库包括墙板、立柱、地面车道线和物资箱；左侧使用渐变暗幕承托文字，右侧展示方块风格的士兵。角色随兵种选择更换臂章颜色和手持武器。预览对象处于独立图层，不含玩家、AI 或网络组件。
- 大厅保留顶部四个页签、任务卡、小队卡和底部玩家代号、单人、LAN 按钮。任务说明与角色分开排布，正文与按钮有足够对比度。作战、配装和设置页使用半透明内容区，使背景保持连续，同时保证文字可读。
- 作战页将原先的空白网格改成由当前 `PrototypeLayout` 中道路、建筑和五个目标点生成的俯视缩略图。赤砂走廊与攻防模式仍明确标为开发中，不能误选为可玩内容。
- 加高配装页兵种卡文字区域，修复 Unity 实际渲染时中文标题被裁切的问题。菜单关闭时释放机库纹理、缩略图纹理和克隆材质。
- 按仓库规则将网页包、LAN 服务显示版本和 Unity 包版本同步到 `0.32.1`。LAN 消息协议保持 `unity-3`。

## 验证

- Unity 6000.5.10f1 编辑器刷新脚本后，在 `SampleScene` 中运行：大厅、作战、配装、设置均可显示；Console 为 0 错误、0 警告。
- 作战页显示道路、建筑和 A–E 目标点；配装页四张兵种卡文字完整。按 `2` 切换医疗兵后，选中态、角色臂章、默认武器名称与数值同步变化。
- 通过编辑器菜单 `IRONFRONT/Build macOS Standalone` 构建；本地 `IRONFRONT.app` 的 `CFBundleShortVersionString` 为 `0.32.1`。构建产物位于 `UnityProject/Builds/macOS/`，未纳入 Git。
- 使用仓库现有 TypeScript 配置运行 `tsc --noEmit` 和 `tsc -p tsconfig.logic.json --noEmit`，均通过。改动集中于 Unity 菜单外观和版本显示，战斗规则与 LAN 流程未变。

## 当前边界

机库和地图缩略图由代码生成，保持当前游戏的低多边形美术语言；它们不代替未来地图的正式场景资产。布局仍以桌面横屏 960 × 600 逻辑画布为目标。赤砂走廊及攻防模式继续保留在规划状态。

开发提交保留在 `codex/unity-port`，不合并 `main`。
