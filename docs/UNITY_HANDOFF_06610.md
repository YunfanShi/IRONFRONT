# 0.66.10 — 旧手臂使用动作包换弹

## 用户要求与结果

按用户“把 Unity 给的动作放在独立五指之前的”要求，以 `ed6143f` / 0.66.9 为基线，为 P8 双队第一人称制作旧手臂候选。使用保留的 `Resources/Soldiers/{Blue,Red}Soldier` 原模型，恢复独立五指改造之前的手套、袖管和硬护臂外观，接入 `Gun_Aim02` / `Gun_Reload02`。

P8 左手随源动作离开握把、移向腰侧、托送新弹匣并回到双手握姿。四指仍共用一根弯曲骨；拇指仍为单独一根骨。IF-27 继续使用现有独立五指和步枪源动作。

## 适配方法

- 源数据沿用 0.66.9：Blender 1–52 帧、103 个 60 Hz 样本，源片段 1.7 秒，按玩法 1.3 秒完整播放，速度约 1.31 倍。[来源与许可记录](../art/characters/p8-legacy-pack-2026-10-27/SOURCES.md)。
- 以旧版已经校准的持枪姿势计算左右腕部坐标转换，跟随源动作旋转；左手位置在旧握持偏移与当前 P8 弹匣插入点之间平滑校正。
- 四个源 MCP 指根弯曲角聚合到旧四指骨，左手按旧握姿校准张合幅度；右手限制在持枪范围内。源拇指变化映射到旧拇指骨。这是源动作驱动的简化映射，无法复现逐指、逐指节形状。
- 沿用 0.66.9 枪身轨迹、新旧弹匣显隐、随手运动、插入末段与弹匣槽对齐；源动作没有枪顶拉套筒段，仍停用旧程序化拉套筒。
- 原模型、网格、绑定权重、材质、枪械比例及玩法时长不变；本轮只更改三个运行／检查脚本和项目版本。

## 校准与验证

第一轮图像暴露旧腕坐标直接映射导致插匣时掌心翻偏，已改为相对旧握姿映射。最终候选为 `build02.log`，Unity 6000.5.10f1 macOS Player 构建 PASS。

最终两组检查均为 `Version=0.66.10`、`RuntimeErrors=0`：

- P8 全段 `pistol`：持枪、瞄准、换弹连续帧及接触观察。
- 红蓝两队七枪 `rig`：原模型网格引用和共用骨、实际持枪／换弹来源、四指随插入阶段张开、原臂长、瞄准视线、五个阶段中断复位。插入交接前弹匣误差小于 1 mm／0.1°，交接后只显示一个就位弹匣。
- 283 张 Player 帧的空白／紫屏检查无错误。实际查看持枪、插入、恢复与反向接触近照，腕部翻偏已修正。原厚护臂仍有遮挡，共用骨抓握依然比独立五指简化；以上数值检查不是逐三角形无穿插证明。
- 15 个基线文件中，12 个保持原哈希，3 个脚本为本轮修改；包括源动作数据、旧／候选预制件、玩家与兵种脚本均未变。见 `validation.json`。
