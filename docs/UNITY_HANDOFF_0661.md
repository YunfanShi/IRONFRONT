# Unity 0.66.1 — 模型／骨骼排查与第一轮修正

2026-10-26。根据用户提供的 P8 第一人称截图，复现双手张开、翻掌、前臂扭曲、比例失衡的问题。结论是手部关节位置、蒙皮、握点语义和第一人称呈现共同造成；仅更换高精度模型不能自动解决这些问题。

**交付状态：排查完成，保留一份第一轮修正候选版；功能回归通过，视觉仍有下列待整改项，不标为所有模型问题已解决。** 当前运行的旧版 0.66.0 没有被关闭或覆盖。

## 已确认的问题与处理

| 问题 | 证据与影响 | 本轮处理 |
| --- | --- | --- |
| 手腕骨落在掌部 | 原 Hand 骨高度 z=.90，实际袖口约 .98；旋转手骨时掌根仍留在前臂上，出现折叠 | 派生 v03 将腕点移至袖口，修正前臂末端与指根位置；Unity 从新骨架计算实际骨段长度 |
| 掌根、拇指错误受前臂驱动 | 控制手骨旋转时，手掌上方突起仍不跟随；源权重检查证实大量前臂影响 | 重分配手腕和手掌区域权重，新增两根拇指骨；每顶点最多四影响且归一化 |
| 第一人称手臂与枪缩放不一致 | 枪按 1/.65 归一化，手臂额外使用 2 倍缩放 | 统一相对缩放为 1/.65 |
| 将枪表面接触点直接当成腕关节 | 骨骼对上标记，实际手掌仍悬空、朝外或穿握把 | 区分 RightContactPosition 与腕部目标；分别校准手枪包握、长枪托枪、弹匣和拉柄动作 |
| 不可达目标拉长前臂 | 原解算只约束肘部，却把手直接放到超出臂长的位置 | 第一人称移动隐藏肩部使目标可达；保持两段骨长，前臂及上臂扭转连续跟随手掌；肩部参考改为摄像机空间 |
| 第一人称表面破损／内侧消失 | 旧处理删除带少量躯干权重的手臂三角面；近景观察内侧时还有背面剔除 | 保留完整手臂三角面，仅重映射非手臂权重；第一人称使用独立双面材质，原身体材质保留 |

手腕重新定位后，前臂骨的长度约从 .317 m 变为 .236 m；这是关节回到正确位置，并没有缩短或重建人物网格。四根手指的原始合并控制仍保留，未伪称已增加完整手指骨架。

## 仍需整改的视觉问题

1. **第一人称专用网格不足。** 当前继续使用全身模型拆出的手臂，近景仍能看到原始肩部／上臂分件边界。双面渲染避免内侧完全透空，但没有把原分件边界修成适合所有近景角度的完整袖子。
2. **护臂轮廓与开镜构图偏笨重。** P8 开镜时护臂仍占据较多下半屏，靠近瞄具两侧。需要专门制作第一人称手臂布局与持枪姿势，不能把功能测试通过当作最终画面合格。
3. **四指共用一根骨骼。** 不能分别表现食指进入扳机护圈、其他手指贴合不同握把；拇指虽可动，近景包握仍粗糙。下一步应先做独立食指和分节手指／掌部拓扑，再逐枪标定握把接触。
4. **装备接触需要单独美术复核。** 六类装备接入和行为回归通过，但不等于手雷、发射器在每个镜头中的逐指接触已经验收。

建议后续顺序：先制作保留现有外观的第一人称完整双臂及手部绑定，再处理七枪持枪／开镜／换弹的近景接触，最后扩大到装备和第三人称极限姿态。避免继续只改几个旋转角度来掩盖网格或关节问题。
