# IRONFRONT Unity 固定直升机主炮、准星设置与动作骑乘交接（0.52.0）

2026-10-12，基于本地 0.51.0。开发仍在 `codex/unity-port`，保留此前所有未提交工作，不合并 `main`、不提交或推送。开始本轮时只读核验远端 Unity 分支仍为 `c166d59`。0.51 及之前规则见 [上一轮交接](UNITY_HANDOFF_051.md)。

## 武装直升机固定主炮

武装直升机的主炮固定到可见机体，炮座和炮管相对于机体保持固定方向，随飞行中的机体俯仰、侧倾一起运动。实际炮弹从可见炮口沿炮口轴发射，不再仅固定外观而继续朝鼠标射击。炮口投影反馈使用真实弹道方向。

腹部机枪保留原独立瞄准和朝下限角；侦察直升机、喷气机以及其他装甲平台的武器瞄准不随本次固定主炮改动改变。

## 准星大小设置

大厅设置与 Esc 暂停菜单增加准星大小滑条，范围 50%–200%，默认 100%。基础准星的间距、划线、粗细及中心点按比例变化，设置界面显示百分比及实时预览，保存后在下次启动时恢复。

设置值拒绝 NaN/无穷值并限制范围。大小只影响基础准星视觉，不改变枪械散布、命中判定、命中 X 或防空目标锁定框。原主音量、音乐音量与鼠标灵敏度继续可用。

## 人物动作与骨架

跑步采用前脚低位落地、后蹬踮脚、抬跟回收、前伸落地的循环，左右腿相差半周期，并加强步幅、重心、扭胯和躯干前倾。长枪采用双手斜抱，双手保持实际枪握点；冲锋枪和手枪采用右手低持、左臂贴身反向摆动。瞄准时恢复稳定持枪，蹲趴、倒地保留原游戏逻辑。玩家普通移动与 Shift 冲刺分别使用步行、跑步动作权重及节奏，AI 依据真实速度混合动作；不再让玩家两种速度都饱和为同一种跑姿。

四肢使用现有两段骨架 IK，保持上臂/前臂及大小腿长度，按真实局部位移识别侧移和后退，暂停、停步和传送不持续空跑。模型更新顺序在玩家枪械表现更新之后，避免手部刚算完握点、枪又移动一帧。游戏移动速度、角色碰撞与生命规则不改变。

## 摩托车模型与骑乘

摩托车补上管式车架、双座垫、轮胎胎块/轮圈辐条、前叉和避震、发动机/油箱、握把刹车、仪表及控制线。前叉随转向旋转，轮胎随速度滚动，车体与骑手有小幅视觉侧倾；原碰撞体、驾驶物理和两座属性保留。

司机双手依实际左右握把锚点解算，臀部和鞋底分别对齐座垫及脚踏。乘客使用后座扶手及独立脚踏。第一人称显示同一套真实手臂并隐藏头身，第三人称恢复完整骑手，退车恢复步行动作及原视角；没有为两个视角重复生成两套手。司机眼点略向后，入座默认朝下 15°，窄窗口保持至少 75° 水平视野，转向两端仍能看到两只手；支持在车上按 V 切换人称。实体仪表显示实际速度及剩余生命值。
