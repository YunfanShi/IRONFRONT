# Unity 0.66.2 — 枪械比例与持枪姿势修正

2026-10-27。根据用户的 P8 腰射及 IF-27 换弹截图，放大现有枪械，并继续修正手部动作。基线为已同步的 `413cf0e`；沿用 `codex/unity-port` 产品分支，不更换或重导出现有模型。

## 可运行版本

`UnityProject/Builds/WeaponFit-0.66.2/IRONFRONT.app`

使用 Unity 6000.5.10f1 构建。旧 `RigFix-0.66.1` 及其他应用保留，没有关闭用户的旧游戏进程。已打开的旧版窗口不会自动加载这次代码，体验本次修改须打开上述新版本。

## 本轮修改

- **六款长枪放大 15%，P8 手枪放大 55%。** 第一、第三人称及大厅使用同一比例。新增运行时 `Weapon visual size` 节点，只缩放枪身、枪托、活动件及其定位点；第一人称手臂仍保持原来的 .55/.65 世界缩放。没有扩大角色双手。瞄准位置按实际缩放后的 Sight 重新计算，伤害、弹药、射速等游戏规则保持原有数值。
- **纠正反向弯指。** 隔离手部实机对照表明，原正 X 弯曲把手指向手背／护板一侧折；改为向掌心的负 X 弯曲，并保留支撑动作的张手过渡。上一轮仅靠骨点附着和骨段长度检查，没能排除此类视觉错误。本轮增加隔离手部、实际蒙皮和连续动作画面。
- **分开标定握持。** 调整右腕姿态和位置、手枪双手包握、长枪掌心向上的托枪，以及换弹时抓弹匣的位置。缩放后的长枪支撑手靠护木后部握持，避免支撑手超出臂长后把整把枪拉进胸前。
- **换弹位置与旋转一起跟随。** 手掌随弹匣移动并随其倾斜，随后过渡到拉柄和托枪姿势；不只跟踪弹匣的位置。不同枪的现有弹匣、枪机、拉柄行程与时间沿用原实现。
- **第一人称双臂布局。** 肘部弯曲方向由摄像机／身体参考系决定，避免跟着枪的换弹翻转一起滚动；肩部按手的位置放在画面下方。保持两段骨长，未用拉长前臂来追逐目标。
- **适配新增层级。** 玩家弹匣引用改用武器组件字段，枪托可见性检查使用新的实际路径，重算 LOD bounds。第三人称给放大后的枪额外留出胸前距离。

## 验证与证据

证据根目录：`art/characters/weapon-fit-2026-10-26/`。目录沿用开始工作的日期，任务于 10 月 27 日收尾。

- 最终构建：`build-06.log`。最后一次只补充弹匣旋转跟随；七枪实际握持、瞄准、射击和换弹相关检查以最终构建重跑。
- `checks/rig`：蓝、红两队 × 七枪；实际枪口到瞄具的距离比例为 1.15／1.55，手臂大小不变；104 个骨段样本；第一人称实际 BakeMesh 生成碰撞面检查中心瞄准线。检查包含腰射、开镜、换弹中段、拉柄及第三人称站／蹲／趴／滑铲截图。
- `checks/if27` 与 `checks/batch2`：瞄准点居中、枪体瞄准线无遮挡、真实枪口发射、弹药扣减、弹匣复位、第一／第三人称手部目标跟随。IF-27 换弹胸前最小距离保持原 .14 m 验收阈值，不放宽测试。
- `checks/motion`：P8／IF-27 的腰射、开镜和换弹连续相位采样。换弹在 90 帧内铺相位，不能当作按真实换弹时长录制的演示录像；IF-27 专项另按实际换弹时长逐帧检查。
- `checks-05/sprint`、`menu`、`equipment`：最后一次不涉及这些机制的改动前已通过。大厅七枪各 201 个采样、两轮循环；冲刺开火／开镜打断、枪托保留；六类装备接入和消耗／部署。没有为最后的弹匣旋转小改动重复无关检查。
- `Blue-review.jpg`、`Red-review.jpg`、`before-after.jpg`、`motion-*.jpg` 为本地画面整理；`frame-checks.json` 是帧质量诊断。最终判定汇总在 `final-validation.json`。

`checks-03`、`checks-04` 保留失败中间稿，不能当作交付证据。它们曾暴露第三人称枪柄过近、托枪手挡住瞄准线，均在后续修正后复核。`sweep-03`／`sweep-04` 是隔离右手的正负弯指对照；参数 JSON 和开发探针可用于复现。

## 保留与边界

本轮只修改运行时呈现和诊断代码，没有改动 FBX、网格顶点、蒙皮权重、材质、贴图或原始 Blender 文件。旧 v02/v03 模型、载具、装备及旧应用均保留。此前五个参考目录文本的本地删除未纳入提交。

当前护臂仍是原模型的厚装甲，近景视觉偏重；袖子原有分件边界也没有通过本轮重建。四根手指仍共用弯曲骨，无法独立表现扳机食指、逐指贴合或精确的拇指叠放。已纠正本轮确认的驱动方向和握姿问题，但不宣称已完成独立手指绑定、全新第一人称手臂或所有近景穿插的最终美术验收。

## 复现

在没有其他 Editor 占用工程时，通过 `PrototypeOptimizationBuild.Build`、`-buildTarget StandaloneOSX` 和 `-buildOutput` 构建。运行 `python3 art/characters/weapon-fit-2026-10-26/run_checks.py rig if27 batch2 motion` 可复核最终相关场景。图表整理脚本 `review_frames.py` 需要 Pillow 和本机 Unity 技能的 ut_review；运行游戏本身不依赖这些分析工具。
