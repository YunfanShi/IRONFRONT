# 0.66.11 — 按参考修正 P8 双手握姿

## 用户参考与范围

用户给出的第一人称图片要求：右手包住握把后侧，左手围住右手，双手在握把处形成紧凑的包覆，袖口退到腕后。以 `a83c1eb` / 0.66.10 为基线，修正红蓝两队 P8 第一人称旧手臂候选。继续使用独立五指之前的原模型和 `Gun_Aim02` / `Gun_Reload02`。参考原图本地保存为 `art/characters/p8-reference-grip-2026-10-27/reference.png`。

本轮调整握姿、四指弯曲轴和旧模型拇指方向，未重建参考图中的高精度黑色手套。IF-27 和其他枪仍走既有路径。

## 根因与实现

### 四指共用骨的弯曲轴错误

0.66.10 对旧四指骨施加 local X 旋转。实际旧模型四指排列轴几乎垂直于 local X；从未修改网格的实机导出测量，右手 213 个、左手 232 个指部顶点得到的轴与旧轴夹角分别约 83.69°、84.46°。旧驱动使整组指头扭转，无法沿握把合拢。

改为绕模型实测静止局部轴旋转：左 `(-.096511, -.027319, .994957)`、右 `(-.109828, .032130, -.993431)`，持枪约 70°。左手仍由四个源 MCP 弯曲量聚合驱动张合，右手保持握枪范围。记录见 `finger-axis-analysis.json`；测量脚本为 `calibrate_legacy_grip.py`，输入是 sweep07 的零四指旋转导出。

### 手腕与拇指适配

- 根据实际手掌方向和四指排列校准左右腕部，左手向右手收拢。最终参数见 `selected-grip.json`，不是早期 sweep 参数。
- 源动作的左拇指 MCP 静止方向接近竖直，原模型只有单段拇指，不能直接复现原包三节拇指的弯曲。增加持枪方向校准，使旧拇指朝前，并在运动的手掌坐标中保留源动作变化。
- 旧手臂使用相机后下方的肩部锚点，减轻袖口对手掌的遮挡。
- 枪身轨迹、弹匣交接、插入对齐、1.3 秒玩法时长沿用；换弹中断或结束恢复新的腕部握姿。

- 新增五个换弹中断阶段的双腕复位检查，容差 0.1 mm / 0.05°。既有弹匣交接 1 mm / 0.1°、单个就位弹匣、原臂长、原网格引用、共用指骨、实际源动作、瞄准视线检查通过。

## 视觉边界

四指仍共用一根骨，只能整组闭合，无法逐指节贴合握把。现有手套较粗、蓝色手背片和袖口轮廓与用户参考仍有差异；这一版校正了可观察到的弯曲方向和双手位置，不代表已复制参考图全部美术细节。数值 PASS 不是无穿插证明，反向观察机位仍可见原袖管截面。
