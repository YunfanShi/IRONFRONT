# 0.66.12 — 左前臂、掌面和换弹拇指修正

## 用户要求

用户指出上一版左前臂过于向内，腕部折角不自然；希望前臂与掌部基本连贯，掌部略向内包住右手，右手继续包住握把。同时指出换弹时左拇指的位置与方向错误：当左掌朝右，拇指应在四指的食指侧。

基线为 `aad5135` / 0.66.11。修改范围为红蓝两队 P8 第一人称旧手臂适配，继续使用原模型、四指共用骨、单段拇指与 `Gun_Aim02` / `Gun_Reload02`。

## 实际发现

1. **左腕折角。** 从上一版实际关节位置计算，持枪时左前臂至掌部轴相差 50.30°，插匣时达到 61.21°。原全身源动作的肘部位置不适合已经移到 P8 握把上的腕点。
2. **左掌上下及掌面方向反了。** 上一版用四指顶点的 PCA 排列轴建立掌部坐标，却未用真实拇指表面确定轴的正负号。不施加弯指时，实际拇指顶点群位于所定义径向的负侧。旧握姿因此把左掌的食指侧与小指侧倒置，掌面也反向。
3. **骨轴不等于拇指表面方向。** 旧 Thumb 骨的 +Y 与完全受该骨控制的 49 个拇指顶点的延伸方向相差 27.11°。直接使 `Thumb.up` 朝向目标，表面仍偏转；单独修箭头曾造成拇指从手背片穿出。
4. **插匣修正后坐标不一致。** 旧拇指目标沿原始源腕旋转，而手掌已额外对齐当前弹匣槽，二者在插入阶段不一致。

基线关节测量见 `baseline-anatomy.json`。几何诊断通过实际 bindposes、骨矩阵与顶点权重进行 CPU 蒙皮计算；不把 Editor 中可能尚未更新的 BakeMesh 缓存当最终证据。

## 修正方法

- 用实际拇指侧确定左掌坐标：绕腕到指根轴翻转错误的左掌基础方向，并同步翻转左四指弯曲轴符号，使四指向掌心合拢。
- 握持时左掌绕指根向内转 30°，腕点向外补偿，以维持包覆右手的指根接触。左前臂与掌部最大折角设为 18°；换弹时平滑放宽到 38°，避免强行拉直手腕把肘部顶高。
- 前臂滚转依据原模型静止绑定关系求解；肩肘衔接在换弹时向相机下方延伸，让上臂裁切端从画面下方退出。上下臂骨段长度保持一致。
- 实例初始化时从旧网格完全受左 Thumb 控制的顶点求出真实拇指方向；之后对齐这个表面方向，而非直接使用骨的 +Y。
- 左拇指以源三节方向均值近似，限制单段旧拇指越到小指侧；持枪时沿枪身压低。通过最终校正后的手掌坐标转换，包含插匣校正与首尾握姿混合。
- 原源动作数据、枪身轨迹、1.3 秒换弹玩法时长和新旧弹匣交接继续沿用。右手与其他枪械的适配保持原路径。

## 最终验证与复现

最终候选为 **build05**，Unity 6000.5.10f1 macOS Development Player，构建 PASS。最终实机目录为 `art/characters/p8-wrist-thumb-2026-10-27/checks/`。

- `python3 run_checks.py pistol rig`：P8 全段和红蓝两队七枪检查；最终两组均为 `Version=0.66.12`、`RuntimeErrors=0`，P8 70 项、rig 223 项检查全部通过。精确结果见 `validation.json`。
- 最终 297 张 Player 帧图无空白／紫屏检查错误。158 个姿势采样中，持枪左腕折角 11.6754°、瞄准 11.1679°、换弹最大 38.0138°，拇指实际表面朝食指侧的分量始终为正（最低 0.2427）。六组独立 CPU 蒙皮姿势的表面方向与驱动轴偏差均小于 0.1°，拇指顶点中心均在四指中心的食指侧。
- `support-anatomy.csv` 记录 30 fps 连续序列和关键姿势的左腕折角、实际拇指表面沿食指侧的分量；检查原臂长、瞄准视线、弹匣交接及五阶段中断后的双腕复位。
- `PrototypeHandGeometryAudit.Run -handGeometryOutput <绝对路径>` 独立导出中性手套、持枪、取匣、插匣和回托的蒙皮顶点。精简结果见 `thumb-surface-summary.json`；原始大体积几何报告留本地。
- `review_final.py` 生成最终空白／紫屏检查、关键姿势表、连续换弹表、左右对比图和视频序列。`summarize_validation.py` 汇总实际测试、表面方向和文件保留哈希。
- 16 个基线文件中，12 个保持相同哈希；其余为本轮三个运行／检查脚本和版本设置。视频编码、8 个抽样帧解码通过：288 帧、9.6 秒、30 fps、1920×800。
- build01–04 为被替代的迭代，其中 build01/02 虽然运行检查通过，视觉仍有错误。不得用其 `checks-build*` 或旧 review 图替代最终 build05 证据。
