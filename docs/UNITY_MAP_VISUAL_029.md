# 0.29.0 Unity 地图与建筑外观

## 目标与基线

本轮从 `codex/unity-port` 的 0.28.0 继续。开始时本地 `HEAD` 与 GitHub 远端开发分支均为 `019802b`。当前 `main` 的 `src/world/Layout.ts`、`src/rendering/WorldView.ts` 和 `src/rendering/EnvironmentArt.ts` 是外观与位置参照。Unity 已使用同一张 720 米地图、五据点和大部分建筑坐标，却只把每个建筑/掩体渲染成单色立方体，也没有原版的道路、铁路、棚屋、通信设施和林木。此次在 Unity 补齐区域识别与建筑细节，保留现有单机及局域网玩法的通行规则。

## 布局与建筑

- 三条主要道路使用网页 `main` 的折线路点与约 11 米路面宽度，外侧加泥土路肩；路面按 `PrototypeLayout.HeightAt` 分段贴合地形。蓝红基地各有一块带阵营色的出发平台。
- A 工业区、B 中央村庄、C 铁路车站、D 军事基地、E 通信设施沿用网页的据点和建筑位置。村庄房屋增加双坡屋顶、山墙、烟囱、门和分格窗；厂房增加深色平屋顶、檐口、门窗、排风设备；兵营采用橄榄色墙面、屋顶装置与重复窗列。不同建筑有独立材质，远处可按轮廓辨认区域。
- 铁路沿网页的 z=47/132 两条线布置道床、双钢轨、枕木和带车窗的车厢；开放式三面围护建筑保持 +z 入口，并加屋顶与地坪。棚屋四柱与顶盖、E 区通信桅杆、三处辅助塔架也按网页坐标制作。
- 箱体与集装箱增加包边、竖向压筋等细节；树林以固定随机种子分布，避开建筑、主路、铁轨、出生区和据点中心。少量碎石点缀空地。

## 实现边界

新脚本 `PrototypeWorldVisual.cs` 只生成可见装饰网格，按材质合并静态网格，减少大量分件对象的开销。`PrototypeRuntime.BuildStructures` 仍为 `PrototypeLayout.Blocks` 创建原尺寸 `BoxCollider`，只是隐藏其旧的单色渲染器；装饰网格没有碰撞体。步兵/载具导航、视线、掩体、射击命中与占点继续使用原来的阻挡范围。T90 静态预览及既有局域网权限逻辑没有改动。地图是基于 `main` 的区域、坐标和造型语言实现的 Unity 版本，局部低矮掩体与 T90 预览仍属开发分支额外内容。

按 `ForAgent.md` 的新模块规则升为 0.29.0；同步网页包、LAN 服务端与客户端版本门槛、菜单标识及 Unity 应用版本。遵从用户此前的分支要求，本轮只提交到 `codex/unity-port`。

## 验证

Unity 6000.5.10f1 刷新脚本后进入 `SampleScene` 的 Play 模式，初始视角能看到贴地道路、路肩、树林及建筑分区，Console 0 错误、0 警告。此为画面与启动检查；完整视角、美术质量和长时间性能仍需后续验收。

- `tsc --noEmit` 通过；`scripts/test-unity-room.cjs` 与 `scripts/test-lan.cjs` 均通过，验证地图外观改动未破坏已有 LAN 房间协议。
- Unity 编辑器的 macOS Standalone 构建成功，应用 `Info.plist` 版本为 0.29.0，构建后 Console 0 错误、0 警告。
- `UnityProject/Builds/macOS/IRONFRONT-Unity-Map-0.29.0-macOS.zip` 已用 `unzip -tq` 验证压缩包完整；构建产物按项目规则留在本地，不纳入 Git。

## 当前限制

建筑内部仍为封闭占位体，仅三面围护建筑按原规则可进入；表面没有完整 PBR 贴图、破坏状态或可交互门窗。植被和碎石纯属装饰，没有碰撞与掩护属性。地表底色、远景与云层还比网页 `main` 简化，后续可补地形纹理、天空和更完整的光照烘焙。道路没有改变车辆 AI 的现有寻路目标，也不代表联机玩法范围扩大。
