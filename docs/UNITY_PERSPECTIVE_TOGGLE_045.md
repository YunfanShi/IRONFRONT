# 0.45.0 Unity 第一、第三人称双向切换

## 用户修正与操作

0.44.0 把玩家步兵固定为第三人称、三类可用载具固定为第一人称。用户进一步明确：人物和载具都需要能在第一、第三人称之间来回切换。本版在战局中用 `V` 切换当前控制对象的视角，与网页原版的视角键一致。Unity 原先的 `V` 卧倒改为左或右 `Ctrl`；`C` 继续用于蹲下和滑铲。底部 HUD 显示 `V view 1P/3P`，便于确认当前状态。

## 实现

| 场景 | 第一人称 | 第三人称 |
| --- | --- | --- |
| 步兵 | 镜头置于当前站姿、蹲姿或卧姿的眼高；隐藏自身全身模型，显示随镜头运动的枪模和双手 | 保留 0.44.0 肩后镜头、可见身体和当前武器，肩后遮挡时相机向前避障 |
| T90、R4、U8 | 使用各自炮手、驾驶员或机枪手的座位观察点，T90 保留较窄的瞄具视野 | 镜头位于车后上方，随鼠标瞄准方向绕车移动；相机射线忽略本车，遇到外部障碍时向前收缩 |

步兵与载具分别记住上次选定的人称：上车切到载具所选模式，下车恢复步兵所选模式；U8 切换驾驶员与机枪手座位时不重置人称；重新部署后保留选择。首次进入战局时，步兵默认第三人称，载具默认第一人称。倒地期间继续使用专门的地面观察视角与约 170° 水平范围，扶起后回到倒地前的步兵选择。

第一人称步兵开火、投掷和发射火箭使用可见武器附近的发射位置；第三人称继续从人物所持武器附近发射。准星目标仍由当前镜头射线计算。载具在两种人称下仍由镜头目标驱动炮塔或机枪，实际炮弹从武器枪口出发，装填和伤害规则不变。

## 验收结果（2026-10-11）

- Unity 6000.5.10f1 的 `IRONFRONT → Verify Player and Vehicle Cameras` 输出 `IRONFRONT perspective PASS`：步兵 3P→1P→3P、两套枪模显隐、三类载具 1P→3P→1P、U8 两座位和下车恢复原步兵模式均通过。编辑器 Play 中目视确认步兵和 T90 的 `V` 双向切换，HUD 显示当前 `1P/3P`。
- `IRONFRONT → Verify Downed View and Revive` 输出 `IRONFRONT downed view and revive PASS`；在步兵第一人称选中时，医疗兵救援后仍恢复第一人称。`Verify Tank and Respawn` 输出 `IRONFRONT smoke PASS`，覆盖部署、驾驶、转角行驶、开炮冷却和离车。测试后 Console 为 0 警告、0 错误。
- Unity 编辑器成功构建 `UnityProject/Builds/macOS/IRONFRONT.app`，应用版本 `0.45.0`。用户随后反馈已提前在独立程序中验证双向切换，功能正确；此项按用户实机确认记录，没有本轮代理独立采集的操作录像。
- TypeScript 主配置检查与 `tsconfig.logic.json` 编译、`scripts/verify-core.cjs` 回归通过；它们验证网页和共享逻辑，不代替 Unity 视角实机验收。

此版仅覆盖 Unity 现有可驾驶的 T90、R4、U8。其他五类载具和访客载具操控仍按逐项还原清单处理。
