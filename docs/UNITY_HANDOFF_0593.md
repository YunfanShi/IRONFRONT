# Unity 0.59.3 — 跑步镜头与上身运动

2026-10-24。根据用户要求增加冲刺时第一人称摄像头轻微抖动、上半身左右小幅转动，模拟跑步时的重心转移。保留原士兵和枪械资产、枪托、下半身步态、移动速度及0.59.2冲刺中断规则。

## 动作设计

- 以角色实际位移推进现有脚步相位，不使用随机抖动。镜头每个步态周期上下起伏两次，左右移动一次；枪械也使用同一相位。
- 摄像头目标位置幅度为左右12mm、上下14mm，并沿用12/s位置平滑；实际画面起伏更小。最大俯仰0.20°、偏航0.10°、侧倾0.30°。
- 原有胸部旋转上叠加3.2°小幅扭转，腰椎使用55%的旋转，胸部总摆幅约±5.2°；与骨盆反向，头部不跟着扭转。持枪跟随65%的新增胸部转动，手部继续使用既有握持IK。
- 运动权重约0.17秒进入、0.10秒退出。开火/开镜优先中断冲刺，停止位移或顶墙时收回运动；镜头位置残余随原有平滑衰减。
- 仅第一人称步兵视角叠加跑步镜头运动。第三人称相机和载具相机保留原逻辑。

## 实现

`PrototypeSoldierVisual` 的位移采样从 LateUpdate 移到 Update，保留执行顺序100，使其在玩家移动后、玩家LateUpdate镜头更新前完成。即使第一人称隐藏身体模型仍更新相位；蒙皮姿势仍在LateUpdate刷新。新增只读 `GaitPhase` / `SprintMotionWeight`，摄像头和持枪直接读取。

权重来自实际水平速度与冲刺状态，传送、倒地、坐车、蹲趴、滑铲、瞄准和装填不启用新增冲刺运动。`PositionInfantryCamera` 每次从玩家方向和俯仰重建基准旋转，避免叠加漂移。腿部求解、身高、脚距、方向平面和速度常量未调整。

## 验证

- 编辑器开发验证通过：实际输入解析、CharacterController移动和开火方法，第一/第三人称各126×2帧；不是物理键盘注入。
- 新增镜头幅度与回收检查、隐藏第一人称身体时仍推进步频、实际碰撞顶墙、停止移动以及第一/第三人称切换。
- 五组既有Play回归最终通过：视角、持有装备、9类载具28次席位切换、大厅和步态。864种红蓝蒙皮姿态覆盖步枪/SMG/手枪握持，跑步姿态启用新增上身转动；另含2304个方向腿部采样。
- 旧步态验证使用反射直接调用LateUpdate，位移采样移动到Update后第一次回归因此失败。已让验证依照真实Update→LateUpdate时序执行，并加强传送清空冲刺晃动的检查；记录见batch-before-sampler-update.txt与最终batch-results.txt。
- 最终独立0.59.3程序验证通过，RuntimeErrors=0；504帧图像与576组运动记录。实测左右位置约±8.7mm、上下约±6.4mm、侧倾约±0.30°，胸部约±5.2°。正常冲刺位移最大误差0.0009m/s。
- 全部504帧检查无空白或异常洋红材质；检查了持枪、左右扭转极值、开镜回收画面。测试场地增加固定立柱和地面线条帮助观察轻微镜头运动，正常游戏不会创建这些物体；第三人称录制使用前侧观察角看清胸肩，正常第三人称相机仍单独验证水平稳定。
- 363个美术和运行资源文件、旧0.59.2程序全部276个文件哈希一致；腿部目标/IK代码段和冲刺输入中断规则一致。见preservation.json。
