# PROJECT IRONFRONT 0.8.0

以 IRONFRONT 0.5.0 为基础的单机 Three.js 大战场 Conquest。保留五据点、AI 小队、侧翼、掩体、撤退、三类大战场事件与无人操作完整战局，并参考 Option A 的操作修复。枪械和模型为虚构的程序化资源；新增本地配乐、独立枪声、CC0 界面和换弹音效。运行不依赖外部素材服务。

## 启动与验证

需要 Node.js 20.19+ 或 22.12+；本轮使用 Node.js 24。源码包包含 package-lock.json，未包含跨平台不兼容的 node_modules。

```sh
npm ci
npm run dev
npm run check
npx playwright install chromium
npm run test:browser
```

已有 Chrome 时，可设置 IRONFRONT_CHROME_PATH 为其完整可执行路径。Playwright 默认使用 Chrome/Chromium WebGL；需要软件后端时设置 IRONFRONT_SOFTWARE_WEBGL=1。结果用于功能 QA。`npm run check` 包含严格类型检查、单元测试、独立逻辑模拟、生产构建。浏览器测试单独运行，不再由 Vitest 错误收集。`dist/` 为可直接部署的构建产物，须通过 HTTP 提供，不要双击 HTML 使用 file://。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 鼠标 | 移动 / 视角 |
| 左键 / 右键 | 开火 / ADS |
| Shift / Ctrl 或 C / 空格 | 移动中点按滑铲、按住冲刺 / 下蹲 / 跳跃 |
| R / 1 / 2 | 换弹 / 主武器 / 副武器 |
| G / X / Z | 投掷物 / 兵种装备 / 工程兵火箭筒 |
| F1–F4（车内） | 驾驶/主炮、机枪、两个成员位（侦察车两位） |
| WASD / 方向键 / 空格（车内） | 镜头方向辅助驾驶 / 传统转向 / 刹车 |
| Q | 战场征用菜单，再按 Q 或 Esc 返回 |
| E | 进入或退出己方载具 |
| M / Tab / Esc / F3 | 战术地图 / 计分板 / 暂停 / 调试 |

鼠标锁定失败时，按住鼠标按钮拖动观察，第一次点击会重新尝试锁定。菜单与暂停态不会继续消耗弹药或触发战斗操作。

## 战场征用积分 RP

开局为 0 RP。击杀 +60、占点完成且在圈内 +120、10 秒内造成至少 20 伤害后的助攻 +25、防守圈内击杀额外 +30、玩家摧毁敌方载具 +150。占点/争夺参与每 5 秒 +5。上限 9999，阵亡保留，重开战局清零。AI 载具击杀不会错误计入玩家积分。

| 支援 | 价格 | 冷却 | 真实效果 |
|---|---:|---:|---|
| 侦察扫描 | 80 | 25s | 目标周围 105m 模糊敌方地图情报，持续 12s |
| 烟幕弹幕 | 100 | 30s | 半径 23m、持续 22s，实际阻断 AI 视觉、射击和 IFF |
| 炮击 | 250 | 65s | 5s 预警后四次真实打击，步兵/装甲受伤，压制与反馈 |
| 快速增援 | 180 | 50s | 18s 内加快己方 AI 复活并提升士气，不扩大队伍人数 |
| R4 侦察车 | 160 | 40s | 基地停车区生成可驾驶轻型车 |
| V12 步战车 | 300 | 65s | 基地生成自动炮载具 |
| T90 主战坦克 | 450 | 90s | 基地生成重装甲、高伤害主炮载具 |
| U8 运输车 | 120 | 30s | 基地生成四座快速运输车，驾驶位无武器 |

支援目标从 A–E 选择，载具固定到主基地。菜单期间暂停战局。余额不足、冷却中、玩家阵亡、无效目标、停车区受阻或征用载具达到上限时不扣分。征用载具最多 3 辆；摧毁后不免费复活，槽位可复用。普通基地载具按类型延时复活；蓝军默认停放 45s，随后 AI 也可投入战斗。

## 出生配装与枪械

主菜单与阵亡部署界面可选择主武器、副武器、装备和投掷物。配置自动保存到本地，下次部署生效；战斗中不能通过配装补满弹药。两槽弹药独立，换弹会扣备弹，切枪取消正在进行的换弹。副武器可选 P8 手枪或 M89 精确射手步枪。

| 枪械 | 伤害 | 射速 RPM | 弹匣 | 有效/最大射程 m | 换弹 s | 倍率 |
|---|---:|---:|---:|---|---:|---:|
| IF-27 卡宾枪 | 31 | 571 | 30 | 92 / 165 | 1.9 | 1.5 |
| M89 精确射手 | 58 | 188 | 12 | 145 / 220 | 2.35 | 3 |
| VX-9 冲锋枪 | 23 | 909 | 36 | 38 / 105 | 1.65 | 1.3 |
| H60 轻机枪 | 34 | 500 | 80 | 110 / 190 | 4.2 | 1.8 |
| BR-44 战斗步枪 | 43 | 353 | 20 | 105 / 185 | 2.5 | 2 |
| S12 狙击步枪 | 92 | 55 | 5 | 210 / 310 | 3.1 | 5 |
| P8 手枪 | 29 | 273 | 15 | 28 / 75 | 1.3 | 1.2 |

各枪后坐力、散布、备弹和自动/半自动行为独立。ADS 采用阻尼过渡；3x/5x 有镜片边缘、遮罩和中心分划。相机和射线共用后坐力方向，随时间恢复。七种第一人称模型分别构造枪身、弹匣、枪托、枪管与瞄具；手枪没有步枪枪托、机枪有弹箱/弹链、狙击枪有枪栓和两脚架，准备界面轮廓也独立，仍为程序化基础模型，并非专业写实枪械资产。

装备：医疗包恢复最多 45HP 并减轻压制；维修工具修复 8m 内己方载具最多 130HP。每次部署两次，10s 使用间隔，无效果不消耗。投掷物每次部署两枚；破片有 1.5s 引信、真实范围伤害和实体墙阻挡；烟雾产生实际视线遮挡体积。

## 载具、AI 和画面

R4：180HP、22m/s、轻武器；V12：420HP、13.2m/s、自动炮；T90：820HP、10m/s、重炮。拥有独立转向/加速、炮塔、射击间隔、射程、模型尺度、碰撞半径与重生时间。双方基地各有四种车，玩家接管蓝军车辆，AI 会驾驶并参与大战场事件。

敌人必须获得视觉接触并等待反应延迟；Easy/Normal/Hard 的基础延迟为 0.8/0.5/0.32s，另加随机延迟。射击使用角度/弹着误差与虚拟飞行时间的移动提前量，压制、移动、距离和士气影响命中；近距离3发、远距离2发短点射，并保留射击停顿。听觉只能产生搜索记忆，不能直接开火。

士兵缩放至约 1.8m，增加护膝、弹袋、肩章及阵营布料；人物继续实例化。近距离 IFF 必须同时满足距离与视线，敌方地图情报也检查视线；侦察支援只提供区域内近似地图情报。烟幕画质低档仍有显示和相同逻辑遮挡。道路、路缘、门框、屋顶设备与原有植被/建筑细节使用实例化批次。图形比例支持 50%–125%。

## 0.8.0 操作与部署更新

A/D 在步兵状态只横移，修复累计相机 roll 造成的持续旋转。死亡后回到战术地图，选择主基地、己方安全据点、安全小队成员或侦察兵信标。交战成员、被攻击/争夺据点用红色标示并禁用部署；点击时重新检查安全性，避免列表显示与实际状态变化之间的漏洞。小队判定包括交战状态、8 秒战斗冷却、压制与附近敌军；据点也检查最近枪火、敌军和敌方炮击预警。

四个兵种拥有固定装备：突击兵 X 补充备弹；医疗兵 X 优先救援附近近期倒地队友，否则治疗；侦察兵 X 放置 180 秒、一次性安全复活信标；工程兵 X 维修、Z 发射两发真实反装甲火箭。装备只有产生实际效果才消耗。G 投掷物数量、X 装备数量、Z 火箭数与冷却在右下角显示。

IFV/坦克驾驶位兼主炮，机枪位独立瞄准，两个成员位不能驾驶/射击。R4 只有驾驶与机枪两个位置；U8 驾驶位无武器。E 在车外靠近可见己方车辆后进入，离开会寻找无碰撞位置。切到机枪/成员位时车停下，本版本没有 AI 同车接管驾驶或独立乘员系统。

主炮与火箭具有速度、重力、飞行时间、实体/地形碰撞与爆炸伤害。只有机枪使用枪线。加入炮口闪光、飞行亮点/尾烟及落点爆炸；这是可见弹体的简化弹道，不是穿甲/跳弹装甲模拟。

AI 步兵有 2–3 发短点射与射击停顿，最多三个步兵同时以玩家为目标；视觉反应、运动提前量、压制、误差、距离与难度依然有效。受击显示来源方向、掉血数值、红色边缘和镜头反馈。

新增实验性“前线推进”：蓝军按 A–E 顺序进攻，红军守卫当前区域；每攻下一区补 40 票（不超过初始票数），蓝票耗尽红胜，全部占领蓝胜。Conquest 默认逻辑保持。地图仍为原有一张，尚未新增地图。

## 配乐与音效

完整个人下载包包含十一首用户提供的配乐：主菜单两首轮播；部署 Suns and Stars；常规交战 Tropic Thunder / Leave No Man Behind；低票劣势 Get Us Out Of Here；接近胜利 Forged in Blood and Steel；炮击 Steel Requiem；反攻 Forged in Blood and Steel；装甲突击 The Burden of Victory；胜利 Tropical Storm-Victory；失败 The Aftermath。曲目映射与原文件名见 docs/MUSIC_MANIFEST.json。

使用两个 HTMLAudio 流媒体槽、2.5 秒交叉淡化及最少 6 秒情境保持，避免短时事件反复切歌。需要用户点击后播放；开火/爆炸降低音乐，暂停降低音乐，窗口隐藏静音。界面提供主音量、音乐、音效和环境四路混音。22 个小型音效缓存解码，最多 28 个采样声音并发；包括七种枪声、主炮、爆炸、两类脚步、近失弹、布料、落地、风声、机械换弹和 UI。

按照用户授权范围，十一首音乐只留本机与完整个人 ZIP，GitHub 及公开源码 ZIP 不含音乐文件。公开版本会平稳降级为音效/环境声；未导入音轨时仅 MP3 集成测试明确跳过，其他浏览器检查仍执行。自行恢复本地音乐：

```sh
python3 scripts/import-music.py /absolute/path/to/Musics_Battlefield
npm run build
```

导入工具需要 FFmpeg；将原文件按清单放进输入目录即可。第三方 CC0 音效来源和许可证见 docs/licenses/Audio-Credits.md；生成音效可用 python3 scripts/generate-sfx.py 重建。本轮验证了真实资源解码、播放进度、音量持久化和切歌，不等于人工听感验收。

最新完整验证：严格 TypeScript、42 项单元测试、8/16/32/64 独立模拟、32v32/500 默认完整战局、生产 Vite build，及浏览器交互测试。详细最终状态见 QA_REPORT.md。多轮短时 headless 采样约30–60 FPS，只说明本机该测试场景，不能当作持续实玩性能保证。
