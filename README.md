## 0.13.0 战斗反馈与准备流程

- 主菜单先选单人或建立/加入房间；载入场景后在独立准备页点选四兵种，再点击枪械、副武器、投掷物图片选配。配置自动保存，复活页继续支持修改。单人准备后 3 秒入场；联机所有当前玩家准备后房主按 START，服务器才推进战局。修改配装会撤销准备。中途加入的玩家先配装再进入。
- 默认 AI 难度改为新兵；首次升级旧配置也切到新兵，之后仍可手动改普通/老兵。反应时间、散布、伤害、点射停顿按难度区分。AI 优先处理附近威胁和小队目标，减少追逐玩家距离，限制同时攻击玩家的射手；小队共享最后已知位置，不读取遮挡后敌人的实时位置。
- AI 四兵种分配卡宾枪、冲锋枪、狙击枪、机枪，并使用治疗/救援（救起玩家后自动退出死亡界面）、补弹、维修/反载具与防空、受压烟幕等真实效果。
- 默认全场 8 辆载具，设置和房主配置可选 0–20。基地活跃载具在两军间平衡；七种型号保留。空投及基地重生都占用上限，上限满则不扣征用积分；征用载具被毁后仍不免费重生。运输车 60 秒、侦察车 70 秒、常规载具 90 秒、坦克 120 秒。装甲突击事件不再绕过等待。
- 弹药物理：坦克 APFSDS 420m/s、重力0.8、范围2.4m；IFV 30mm HE 180m/s、重力4、范围4m；AA 35mm 280m/s、重力1.5；直升机70mm HE 115m/s、重力3、范围6m；喷气机25mm AP 330m/s、重力1。坦克近似直线，小爆炸半径和更高破甲；炮塔转动受速率与射界限制。AI 共用弹道并按难度降低伤害。
- 对人和装甲的实际损失生命值产生命中确认、伤害数字、击毁/击杀标记及声音、尘土和金属火花。轻武器只能对装甲造成很小伤害。枪线改为较淡短时分段曳光和移动亮点，仍从模型枪口产生；手枪/栓动部件有回动动画。
- V 切换步兵和载具第一/第三人称，右键瞄准暂时进入瞄准视角。第三人称摄像机检查建筑遮挡。工程兵 B/6 防空装备显示目标捕获、距离、装填、弹药耗尽，扩大有效捕获锥至450m，三维检查遮挡，不锁地面或己方目标。工程维修工具可按住使用，有间隔但不消耗一次性工具数量。
- HUD 装备为图标、快捷键和数量格；受击显示方向弧与生命值损失。入场为实景摄像机下降加任务倒计时；结算为实景摄像机移动、胜败徽记、成绩与小队卡片动画。不是从其他游戏复制视频或美术资产。

房主先 Ctrl+C 停旧进程，再 npm run lan。端口仍为7878，朋友通过设置中的完整房间链接加入，无需自己的游戏包或服务器。双方需使用0.13前端/服务。

# PROJECT IRONFRONT 0.13.0

在 IRONFRONT 0.5 核心上继续迭代，继承 Option A 操作修复。Three.js 大战场包含征服、前线推进、四兵种、七种枪械、小队战术、三种大战场事件、征用支援、七类载具与真实局域网房间。人物采用原创方块风格：蓝红制服区分阵营，真人佩戴金色胸章。没有使用 Minecraft、战地或三角洲的商业模型。

## 0.12 使用变化

- G/4、X/3、Z/5、B/6 只取出手雷、兵种工具、反装甲、防空装备，不自动使用或扣数量；左键才使用，1/2 切回枪械。装备使用后保持拿在手上。工程发射器只给工程兵。
- 空直升机有重力、旋翼动力衰减与撞击伤害；空喷气机保持惯性后下坠，喷气机需前进速度维持升力。飞行仍是简化模型。
- 房主运行 npm run lan，使用终端“朋友访问”或 Esc 设置中带 ?room=房间码 的完整分享链接。朋友只需浏览器打开，地址、端口、房间码自动填写，再点击加入。
- “测试连接”检查 HTTP 服务，入房前校验房间；连接失败显示具体阶段，网络等待有超时。0.0.0.0 不是分享地址。请先停止旧房主服务，再运行新版本；不要把旧服务与新前端混用。
- LAN 入房会等服务器确认配装后才进入；联机枪口偏移受服务器校验，自己的短枪线跟随当前可见枪口，炮弹仍来自真实车载炮管。

## 单人或联机，自由选择

菜单的“单人游戏 / SOLO”直接启动本机 AI 战场，无需创建房间、连接 WebSocket 或等待其他玩家。即使通过 `npm run lan` 提供的网页访问，仍可选择单人。局域网房间是可选入口。

联机后按 Esc，在连接信息设置中查看当前连接 IP:端口、六位房间码；房主还能看到服务器本机 IPv4 的可分享网页地址。其他人用该网址和房间码加入，无需下载游戏包。VPN/虚拟网卡可能提供多个地址，应选择与朋友同网段的地址。

走路恢复单机每帧加减速、碰撞、脚步与镜头流程。联机客户端本地预测步兵移动，服务器依然权威；小幅误差分帧校正，复活、换阵营、上下车和大幅位置变化直接采用服务器状态。车辆控制仍由服务器负责。

## 启动

推荐 Node.js 24；本轮验证使用 Node 24.15。`npm ci` 安装当前平台依赖，不要复制旧版本的 node_modules。

```sh
npm ci
npm run dev
```

个人完整包包含 11 首本地配乐和构建后的 dist。公开 GitHub 和源码 ZIP 不包含这些 MP3；通过 `scripts/import-music.py` 与 `docs/MUSIC_MANIFEST.json` 导入本地音乐（详见脚本 usage）。音效包含 29 个可离线使用的样本，来源与许可见 docs/licenses、RECORDED_SFX_MANIFEST.json。

## 局域网：开房、合作、对抗与 1v1

房主先运行：

```sh
npm run lan
```

服务在 0.0.0.0:7878 提供游戏网页与房间服务。房主打开 `http://localhost:7878`，在菜单设置规模、模式、票数、扣票和难度，选择是否启用 AI、加入者默认己方/对方/双方交替，然后创建房间。将本机局域网 IP:7878 与六位房间码发给朋友；朋友打开该地址并输入房间码加入。也可从开发页面连接同一房间服务。浏览器页与服务须保持 HTTP/WS 或 HTTPS/WSS 同源协议兼容。

最多 8 名真人（含房主），每个小队最多 4 人；开启 AI 时，小队空位由现有 AI 单位占用。关闭 AI、将加入者设为对方，即可 1v1。暂停菜单中房主可重新分配真人阵营。两队拥有自己的基地、据点、载具、支援与小队部署；关闭 AI 后不会暗中复活 AI。房主分配接口需要创建房间获得的主持凭证，普通加入者不能变更阵营。

房间战局由 Node 服务端以 20Hz 计算。客户端发送操作而不是坐标/血量；射击、移动、弹药、伤害和占领状态共享，玩家背包和 RP 独立。单人暂停停止模拟；联机暂停仅暂停自己的操作，其他人的战局继续。退出关闭连接，开启 AI 的房间由 AI 接替离开者，禁用 AI 时移除离开者。重开按钮返回单人新战局。

## 战斗与部署

击杀、助攻、防守、占点、摧毁载具、实际治疗、实际维修、救援、小队部署和占领贡献获得 RP。Q 支持 11 项支援：侦察、烟幕、炮击、快速增援、侦察车、运输车、步战车、坦克、防空车、直升机、战斗机。征用载具 8 秒空投，驾驶位保留召唤者；空车不会自己动。

AI 使用真实驾驶位和机枪位。连续移动与低频战术决策分离，炮塔转速与射界限制控制真实发射方向；不能凭准星瞬间向坦克后方开火。炮弹从实际炮管末端产生并飞行、碰撞、爆炸。防空车优先瞄准空中敌人，工程防空弹需要瞄准锥内敌机，消耗弹药并制导追踪。飞机采用简化高度/航向控制。

死亡先倒地、停留并升空，随后进入地图部署。队友近期射击/受击时不可部署；警觉或附近存在敌人不会单独锁住队友。己方被攻击据点仍可选择，落点在 42–82 米外，找不到安全空间则拒绝本次部署。可选择己方载具的具体空座位；满员、交火、已毁、未落地及别人保留的驾驶位不可部署。按钮点击时再次检查，避免过期状态。烟幕影响实际感知/敌我识别。

HUD 提供地图载具类别、右下角弹药/装备数量、占点百分比、中央加分、受击方向、自己的车况与炮塔状态。仅可见的己方其他载具显示头顶 HP，敌方和自己的载具不显示头顶 HP；低于 45% 的车辆冒烟。

## 当前边界

方块人物和程序化场景是本轮选定美术方向，不是参考图的 AAA 写实资源。载具和飞行采用简化物理，没有完整空气动力、装甲分区、跳弹、导弹诱饵或新地图。LAN 已实现真实合作/双方对战，但不包含公网匹配、自动局域网发现、完整延迟预测、断线续局；多人跳跃/滑铲呈现仍不完整。实际跨电脑网络和长时间满载 FPS 尚未验证；自动浏览器采样不是性能保证。人工音效听感需要实玩确认。
