# 美术制作资料

当前可运行的 Unity 模型、贴图、材质、预制体、字体、音效、音乐与动作采样文件均随 `UnityProject/Assets/` 提交。使用 Unity 6000.5.10f1 打开项目即可导入现有资源，不需要先运行本目录的制作脚本。

本目录同步制作脚本、来源与许可说明、参数清单、文本验证结果，以及 `Build Runtime Soldiers` 所需的两套 `rigged-v02` FBX。脚本中的原始素材路径和部分证据路径对应制作机器；重新制作源模型或复现截图时需要本机保留的原始素材。

大体积 Blender/GLB 工作原件、重复导出与压缩包、参考图片、录屏、逐帧截图、历史备份继续保存在本机，不纳入此次 Git 同步。本目录不是完整美术工作档备份；这些忽略规则不会删除本机文件。动画来源见 `characters/lobby-idle-2026-10-25/SOURCES.md`，字体许可随 Unity 工程保存。
