# 双方载具独立视图

这里有 9 类载具 × 2 个阵营 × 4 个视角，共 **72 张 PNG**。这些图片从上一级四视图参考板按分隔线直接裁切，未重新生成、缩放或改变涂装。

文件名格式为 `<blue|red>-<车型代号>-<视角>.png`：

| 后缀 | 视角 | 来源格位 |
| --- | --- | --- |
| `front` | 前视图 | 左上 |
| `left` | 左侧视图 | 右上 |
| `back` | 后视图 | 左下 |
| `top` | 顶视图 | 右下 |

车型代号：`t90` 坦克、`v12` 步战车、`a40` 防空车、`r4` 侦察车、`u8` 运输车、`m2` 摩托车、`h8` 武装直升机、`r3` 侦察直升机、`j20` 喷气机。使用图生 3D 时，按一个车型和一个阵营选同名前缀的四张图。

裁切只解决四格分离；原始生成图中的局部视角差异仍需在建模时复核。裁切坐标和可复现脚本见上一级的 `split-views.swift`。
