## 生成提示词要点

- 用途：`stylized-concept`，面向图片转 3D 的游戏步兵三视图。
- 主体：一名约 1.8 米成人比例的虚构装甲步兵；头盔、深色护目镜、护颌、胸甲、弹袋、腰包、小背包、护肘、护膝、手套和战术靴。
- 镜头：正面、严格左侧、背面正交视图；各图人物大小、姿势、装备结构与灯光保持一致。
- 姿势：站直，双臂略离开躯干，双手可见，双脚略分开；不持枪。
- 材质：风格化军事游戏美术，清晰的中低多边形轮廓与低饱和颜色块；蓝队灰蓝制服与浅冷蓝识别板，红队灰棕制服与暗陶红识别板。双方共用同一基础造型。
- 排除：背景、地面、文字、数字、徽章、旗帜、武器、额外角色、强透视和裁切。

这些是建模输入图，不是已经完成的 3D 网格。生成的模型仍需检查正背侧一致性、人体结构、拓扑、贴图、骨骼和 Unity 中的实际效果。枪械应单独制作模型，便于四兵种换装。
